# NovaBoost

Free, open-source Windows gaming and PC optimization toolkit.

## Goals

- Native C# WPF interface.
- Transparent Windows settings and cleanup.
- Reversible gaming profiles.
- No subscription, advertising, paid tiers, or locked features.
- No disabling Windows security or essential services.
- No fabricated FPS guarantees.

## Build

Requirements: Windows and the .NET 10 SDK with WPF targeting support.

```powershell
dotnet build .\NovaBoost.csproj -c Release
```

## Safety

Review every change before applying it. Windows editions differ, and a power-plan change can increase electricity use. Performance varies by hardware and game. Measure results in the same game scene and settings.
